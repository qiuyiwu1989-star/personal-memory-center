## 目标结构

原件及附件保存在私有COS；数据库保存可见消息/片段的检索文本或受控引用、来源角色、原文位置、归属、陈述、语气、时间、状态、版本和派生依赖。系统盘放应用、临时处理与可清理缓存，不作私人原件唯一存储。

数据库是治理记录底座；MD是人可读主题投影及导出形式。用户编辑MD产生候选差异，经同一写入通道形成记录修订，再重建MD。不得同时维护一份“文件真值”和一份“数据库真值”。

Evidence/Claim/Change/Episode/Procedure/Commitment是逻辑对象，先复用现有表、增补列和视图。没有必要为每种对象起一个服务。原子库继续用于素材挖掘，未来通过共同来源ID/记录关联接入，记忆层补归属、时效和治理；不提前迁移整库。

读取：鉴权及范围过滤 → 按当前任务选择原文/可信记忆/经验 → 召回 → 时间及状态筛选 → 去重、冲突提示与短证据包 → Agent回答 → 必要时展开原文。

写入：可见原文归档 → 路由材料性质 → 原子证据与模态 → 候选 → 静态及语义检查 → 关联/冲突预览 → 按已授权治理规则采用 → 索引/MD投影。原文档案可先使用，不依赖全量提炼完成。

## 六个阶段及可执行任务

预计分六次可验收交付，不承诺未经测量的日历工期。每阶段完成必要测试后交付；是否恢复模型队列另有质量门槛。

### M1 可靠读取的基础

- **T01 契约同步**。逐项对照实际MCP七工具、REST与Skill；明确候选搜索≠可信上下文，默认归档、来源读取权限、分页、预算和失败行为。维护单一工具说明源及契约测试。验收：只读Agent能读、不能写；Skill不会引导加载整库或假装调用工具。
- **T02 原文发现索引**。从已校验归档建立owner/scope隔离的可见消息/片段索引，含角色、标题、日期、原文位置和内容哈希。不索引thinking为个人证据。先验证中文全文实现和索引规模，选全文/分词/字符检索基线，不默认假设Postgres英文分词适用中文。迁移仅建索引/伴随表，历史归档不改。验收：预定原文任务能找到支持片段；助手草稿/文章内容有明确标签；无越权。
- **T03 原文MCP入口**。增加最少的原文发现入口，返回短片段及可展开定位；继续使用已有source_get分页，补归档结果到安全可读来源的映射。仅提供搜索命中，不冒称个人记忆。验收：未提炼材料也可检索、引用、回查；无权限结果连标题与计数也不泄漏。

### M2 写入质量与上下文使用 并行两条线

- **T04 原子证据与语气**。处理同段“已有事实+希望角色”，表达事实、希望、考虑、计划、决定、完成、取消或未知；不只看kind。保留否定、条件、程度词、列表和主体指代，不机械逐句切断关系。原文/offset不变；模型不获准裁定身份合并。验收：固定失败例与未见正/负例分别评分，不以全空输出通过。
- **T05 归属、时间与冲突**。复用现有holder/subject_id/as_of/valid_until/created及版本，明确source_date是消息日期。补system-known/revision时间与现实有效区间的表示，缺失为未知；测试迟到消息、相对日期、摘要更新日、同名不同人和不同场景共存。新增模态/时间字段需增量迁移；旧记录标未知，不自动填核实时间。
- **T06 任务证据包**。复用memory_context及现有分页，返回三类可区分内容：可信记录、带出处历史报告、未解决冲突/不足。首版默认仍保留可信过滤；历史报告使用显式档案路线，不暗中放宽trusted策略。附why_retrieved、适用范围/时间及来源展开入口，文字和JSON总量有硬上限。验收：Agent能答“当时怎么说”，不会因此答成“现在已经如此”。
- **T07 端到端评测**。冻结至少30个私有任务，包含可答/不可答、历史/当前、名字/数字/否定、资料挖掘、纠错；标来源支持和期望答案性质。按完整对话/来源分开发集与测试集，写入器不看未来问题。固定底模/源版本/预算，对比原文全文、现有候选、二者组合；逐项评检索与最终答案，保留警告与误拒。

M1与T04可并行；T05/T06依赖T01，原文路线依赖T02/T03；T07设计先冻结，运行依赖T04–T06。不按看过的测试问题加专用词或改原合同。

### M3 变化传播与撤回

- **T08 派生依赖登记**。记录片段/记录版本→MD、索引及缓存的依赖；更正后立即停止旧版可信使用，后台可重建派生物。重建读原文和治理状态，不摘要套摘要。验收：同一纠正后两种Agent读到新状态，可在权限内解释旧误解。
- **T09 双时间回溯与冲突关系**。补supersedes/retracts/contradicts的清楚语义；按主体、属性、范围和有效区间判断冲突，不按最新入库覆盖。验收：迟到消息不能冲掉后来的有效事实，历史时点和当前查询各有正确结果。
- **T10 停用、撤权与删除**。明确“不主动使用/暂停使用/撤销共享/从检索移除/彻底清除”不同操作。停用和撤权即时生效；物理删除通过可审查计划与后台执行，不为讨论计划直接删除。依赖链覆盖COS、数据库、MD、索引、缓存和系统可控导出；备份有声明期限及恢复屏障，第三方已交付副本边界单列。验收：存储凭据+同义检索+备份恢复演练，不能只靠回答不提及证明删除。

### M4 后台工作台与受控自动整理

- **T11 统一的记忆详情**。保留现有导航和视觉样式；详情展示原文/人物归属、事实或意愿、来源日期/有效时间、治理状态、历史版本和修改影响。上传资料卡显示归档、候选提炼、待核实、已采用等不同进度及再次提炼入口。开发预览使用合成内容。
- **T12 两种速度的整理**。归档与显式更正快速处理；批量去重/摘要/可选关系在后台低优先级处理。内容哈希+方法版本去重，重试幂等，暂停/恢复/未知计费可见。建立影子候选分支和差异采用，不覆盖旧结论。验收：重放不重复发起已完成模型请求且采用幂等；未知用量保留预留，新重试请求正常计量，权限撤销不等夜间任务。
- **T13 自动化采用策略**。技术性归档、精确去重、失效传播、MD投影自动；低风险来源报告可按明确可审计策略自动整理为历史候选。身份、重要关系、当前有效状态、长期偏好泛化与权限扩展不得由Agent静默核实。减少逐条人工确认的方向是风险分级和可撤回批次；未来改变trusted准入需先明确规则并验收，不把本计划当成修改现行核实权限的授权。

M4可先用合成数据做界面原型，正式修改影响/删除入口依赖M3。不要在界面混成一个“记住/忘记”开关。

### M5 多源接入与语义检索实验

- **T14 统一来源协议**。适配对话、用户文档、会议转录、笔记与未来原子库：原始角色/说话者、引用区、附件、日期、原文位置、来源哈希和读取权限进入统一envelope。转录不猜说话者真实身份；用户上传不自动等于用户认可正文。原文保留、中文显示单独投影，原姓名与ID不翻译。
- **T15 受控多源试点**。每个新来源冻结验收合同和未见材料，分别检查支持性、归属、时间、模态、长期价值与来源发现。已知问题修复后才扩大，不要求每个来源必须抽出记忆。验收报告必须说明覆盖来源、样本选择偏差和未覆盖类型。
- **T16 混合检索消融**。全文基线成立后，单独加向量：只embedding变化片段、按内容哈希缓存，更新/删除依赖M3。不固定采购新向量服务；先核查现有Postgres扩展及资源。查询embedding计入成本；重排只在明确需要时启用。验收：相同任务、相同预算提高支持证据召回/最终回答且不恶化越权与错误使用，不凭词法或向量相似度判断真值。

### M6 经历与程序学习的轻量试点

- **T17 经历和承诺**。记录任务目标、关键选择、执行结果、外部验证、未完成和失败；commitment独立记录状态、下一步、期限及授权引用。记忆中心不是新的任务编排平台，可先关联现有任务。计划过期只变成过期/未知，不自动变成已完成。
- **T18 经验到Skill及可选图层**。选择一项低风险可重复流程，生成经验候选，包含适用条件、失败条件、来源和测试结果；独立版本评审后才形成Skill差异，授权仍由运行时控制。Graphiti/Cognee等仅在关系/多文档任务明确需要时做旁路消融；无增益则不加入核心。不上全库图、大规模日常反思或参数记忆。

## 质量门槛与恢复处理

写入、可信使用、检索问答、权限和预算分别验收。机械检查/Agent审阅均不代表本人已认可；本计划不会批准旧候选或恢复旧队列。

固定回归必须没有未解决的来源错配、主体混淆、意愿升格、否定丢失或相对时间造数；明确正例不能因空结果躲过。新未见数据需独立审阅，报告所有警告。30题是首版工程验收集，不是统计可靠性证明；不以少量零失败宣称真实世界零风险。

发现跨用户泄漏、撤权后使用、删除内容重现、记忆授予越权动作时，阻断相关路径发布/扩量。语义错误阻断自动采用，不必阻断安全的原文归档及只读发现。这些硬边界不能用平均准确率抵消。

实际处理恢复顺序：质量规则及未见试点通过 → 根据预设证据/审核规则作单独放行判断 → 按来源价值与不确定性选择一小批 → 运行与抽查 → 逐步增加。旧2189历史候选与旧批次不自动继承新方法质量；先按问题分类和来源hash筛选，只有需重新提炼的来源才调用，保留旧版本。人物/身份等高影响候选不自动升格。

## 成本与预算

| 环节 | 是否新增模型成本 | 控制策略 |
| --- | --- | --- |
| 归档、校验、来源定位、权限、全文索引 | 无新增提炼LLM调用 | 哈希和增量索引，现有服务器资源仍有成本 |
| 候选抽取及语义检查 | 有 | 固定版本、小批、保留失败计量，不无限重试 |
| 元数据附加、MD投影、时间过滤 | 无新增提炼LLM调用 | 从记录生成，索引不作事实源 |
| Skill/MCP读取 | 服务端检索可无LLM | 返回内容仍消耗调用Agent上下文tokens |
| embedding、查询语义向量、可选重排 | 有模型/计算成本 | 单独消融、变化块缓存、按需开启 |
