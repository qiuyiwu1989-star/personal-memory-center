# 轻量检索规则 v2

此规则在真实问题相关性回放之前，由合成、跨领域测试固定。它不调用模型，不引入向量数据库，不改记忆事实，也不改变权限、有效时间和治理状态。

## 匹配规则

- 空查询保留默认列表顺序；非空查询没有有效匹配时返回空列表。空结果不意味着质量通过。
- 文本做 NFKC 和小写归一化。中文以连续双字片段及完整短语匹配，不再因为共享一个常见汉字而命中。
- 完整中文短语可以命中；长短语的局部匹配至少需要两个不同双字片段。两字查询可以独立命中。
- 单个汉字只允许与明确的 subject 或已登记 subject_id 完全一致，不在正文广泛匹配。
- 拉丁词按边界匹配； index 不会命中 indexing， fig 不会命中 configuration。常见提问包装不参与评分。
- 每个匹配单元只取最强字段权重，重复出现及原文/中文显示双份不会重复加分。

权重：实体字段 6、原陈述/显示陈述 4、来源标题 3、范围 1.5、类别 1。完整中文短语和完整拉丁词获得额外倍数；同分沿用输入顺序。quote 不参与搜索，以免稿件或参考证据中的词掩盖陈述本身的主题。

## 接入契约

`rank_records(rows, query)` 返回原始行的有序列表，不写入 score 或修改行。输入必须已经做 owner/scope 隔离。

`score_record(row, query)` 返回词法分数，可用于可信上下文相关性排序。查询非空时，治理优先级应只在同相关性分数时作次序因素；空查询可继续原有优先级排序。治理可用性筛选必须独立存在。

算法版本为 `lexical-v2`。新增 helper 的八组合成测试覆盖共享单字、长短语局部匹配、问句包装、拉丁边界、实体/标题权重、重复不膨胀、单字实体及不变性。

## 实际局限

这是词法召回，无法理解同义词、代词、隐含主题，也不能证明语义相关。两份材料出现相同词仍可能是假命中；严格匹配也可能漏掉用词不同的材料。真实任务需同时标注应召回与不应召回，再比较 precision 与 recall；无标签的空结果不得当作成功。

标题/范围命中只说明材料属于该讨论，不证明内容属于某人或现在仍有效。陈述是否可信继续由来源归属、时间和治理状态决定。不得为了使十道问题通过而修改关键词名单、阈值或伪造验证状态。

## 主任务对照后的发布决定

冻结规则后与同一私有相关性契约比较：严格模式减少不相关返回，但正例召回从约70.8%降至25%。因此不替换生产默认。
`Store.snapshot`、可信 `context`、MCP `memory_search` / `memory_context` 新增显式 `retrieval_mode`：默认 `lexical-v1` 保留原行为，`lexical-v2` 为实验选项；无自动切换或候选事实回退。调用结果带方法标识，单字宽泛匹配仍是默认基线的已知局限。
严格模式在可信范围内以相关性排序、同分再按治理优先级；默认模式及空query维持原优先级。两种模式均保留来源、时间、权限及字符预算关卡。
下一步应使用独立的更多问题和标注验证兼顾精度、召回的方法，而不是按这十题加入专用关键词。
