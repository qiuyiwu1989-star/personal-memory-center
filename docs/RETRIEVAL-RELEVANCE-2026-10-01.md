# 检索相关性固定契约与基线

本轮新增零模型调用的相关性评分器，将候选检索与可信上下文评测分开。真实十个任务、16 条候选的逐条标注与证据定位保存在私有目录。公开代码与测试仅含合成数据。本轮不改生产记忆，不批准真实候选。

## 标注口径

标注者为 Agent，已查看来源、已有抽取结果和旧基线；因此是**临时相关性审阅**，不是独立人工 gold，也不是盲测。标签在新排序比较之前冻结。后续应增加未参与开发的任务及人工复核，不能用这十题证明全面质量。

每题对完整的 16 条候选标注。2 表示直接回答限定任务，1 表示背景支持，0 表示无关或不应返回；本轮直接相关阈值为 2。项目单次约束不升级为全局长期偏好，二手摘要可以与回查任务相关，但仍不得称为已证实的当前事实。可信上下文均预期为空，因为真实记录未获核实。

四项有直接相关候选的任务是写作边界、项目配置、写作风格、人物归属。六项无直接相关候选的任务是写作结构方法、大纲参考、课程讲稿、长期偏好、助手建议、临时续写。其中大纲、讲稿与助手参考内容应通过档案入口查询；候选没有命中是分流口径，不代表资料不存在，也不代表档案检索完成。

契约附预期 source ID、message ID、原文引用 SHA-256、来源类型、每条相关/禁返的理由。评分器检查输入和结果 receipts、任务集合、固定 query、完整标注和返回身份。评分不调用模型；候选出处的存在也不证明其概括完全正确。

## 旧基线结果

| 指标 | 旧词法基线 |
| --- | ---: |
| 有直接相关目标的任务 | 4 |
| 无直接相关目标的任务 | 6 |
| macro Precision@5 | 0.2500 |
| macro Recall@5 | 0.7083 |
| macro MRR@5 | 0.7083 |
| 负例正确弃答 | 0/6 |
| 不相关返回次数 | 38 |

同一记录在不同任务返回分别计数。Precision@5 的分母固定为 5，缺位会影响正例精度；Recall@5 的分母为封闭抽取语料中该题全部直接相关候选；MRR@5 取首个直接相关项排名的倒数。三项宏平均仅涵盖四个正例任务。零目标任务的精度、召回与 MRR 返回 null，单独检查是否返回了不应返回的内容；空结果不能充当完美召回。

这是**抽取后封闭语料召回**，无法计入提炼漏掉的事实、完整原始档案或未核实当前状态。当前可信上下文为空不能证明实际 Agent 使用有效；这些指标不自动打开质量关卡或模型队列。

## 复跑与比较

新旧排序必须保持相同输入、相同抽取结果、相同十个 query 与固定契约。不能根据新结果修改标签；确需修订时创建新版本，同时重跑两组，不覆盖旧标注。

```sh
python scripts/score_memory_relevance.py \
  --contract /private/retrieval-relevance-contract-v1.json \
  --report /private/retrieval-report.json \
  --output /private/new-scored-report.json
python -m unittest discover -s tests -p 'test_memory_relevance.py' -v
```

输出文件独占创建、权限 0600，拒绝写入公开仓库；标准输出只有汇总，不输出真实来源或身份。测试覆盖排名指标、正例空返回、负例误返回、背景与直接相关区分、receipt/query/身份/标签漂移拒绝。

下一步在同一冻结契约上比较改进排序，再增加零命中、跨语言、旧决策被更正、项目限定与同名人物等独立留出题。现有十题的统计只用于开发诊断，不宣称人工认证。
