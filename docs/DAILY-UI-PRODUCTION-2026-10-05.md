# 日常记忆工作台 UI 生产上线 · 2026-10-05

本轮只发布 `admin/memory-agent.html` 与 `assets/memory-center.js`，日常使用入口已上线。用户最新要求先做完能用的部分、边用迭代；本轮沿用既有明确上线授权，在最终集成 **546 项 Python / 20 项 Node 全绿**、公开扫描与差异检查通过、UI 文件冻结后执行。

## 用户可用的变化

页面增加紧凑入口：拖入资料先归档、补充个人记忆、核实当前范围候选。个人补充明确切换到 personal，保存后仍为候选；资料归档不调用模型。预算用尽时，归档、人工补充和核实仍可使用。personal 空态区分候选与可用记忆。

修复快速切换记忆范围时刷新被丢弃的问题，新请求会在当前刷新结束后加载最新选择。核实后记录离开候选筛选时给出解释。

这些交互已用合成 DOM 回归及私有合成本地浏览器验证。它们不等于真实模型提炼质量，也不等于已登录生产用户实测。
