# 后台 Agent 凭据管理

本人登录后，在记忆中心“设置 → Agent 接入”管理独立凭据。已授权范围才可选择，默认30天，最长90天。read是基本权限，source_read单独选择。write仅允许一个已获本人授权的 agent:*‑inbox 收件范围，不能包含personal、历史或项目范围；此界面不自动创建新scope或扩展本人权限。收件范围登记仍需独立配置，不通过输入任意scope绕过。

凭据原值仅创建响应显示一次；服务端持久化哈希，不存可还原值。列表只显示用途、范围、权限、到期与状态。相同请求重试只返回既有凭据摘要，不恢复原值；网络失败导致原值遗失时撤销后使用新请求键创建。并发同键仅一个请求取得明文。

凭据管理只允许trusted_user=True的本人及已有write权限，第三方Token不能申请、核实或管理其他Token。使用网站会话登录时继续执行已有Origin与X-Memory-Local的写操作防护。撤销和到期在下一次REST或MCP认证立即拒绝，不依赖重启。注销、关闭、Esc和身份/范围变化清除本页明文；旧异步响应不得重新显示凭据。

此管理功能不修改账号密码，不设置模型API Key，不改变处理预算。创建收件write权限也不等于允许自动提炼或把候选核实为长期事实。

验证使用合成Token和临时配置文件：首次展示、同键幂等冲突、16并发一次明文、只读/跨owner与scope限制、写入范围隔离、过期与撤销、本人Cookie鉴权与CSRF、REST/MCP即时撤销。生产试验不生成测试资料。
