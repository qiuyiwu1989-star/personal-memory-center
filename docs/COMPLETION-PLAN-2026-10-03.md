## T02 / P0 真实质量验收

- 负责：独立评测 Agent B；启动条件：与 T01 并行准备，方法固定后执行；沿用任务：N03。
- 工作：建议先选 12 份完整来源：6 份开发诊断、6 份未参与调参的独立验收。覆盖本人决定、第三方发言、后续更正、条件计划、临时任务、文档或会议；覆盖不足就补样本，不凭数量放行。先写来源标准，再看输出。

## T06 / P1 渐进检索与成本

- 负责：主 Agent / 检索开发；启动条件：可先准备；可信效果依赖 T04；沿用任务：N10 / N12。
- 工作：保持小背景→任务检索→精准原文。固定真实任务，对比无记忆、原文、治理上下文，记录更正一致性、出处、全链路用量。进一步解决候选证据包内部近全量加载；测数据库读取和内存，不只看返回字数。
