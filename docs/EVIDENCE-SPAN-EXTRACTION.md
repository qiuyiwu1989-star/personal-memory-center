# 片段证据抽取 v9

新的输入适配器用无模型规则分流明确章节大纲、长角色规范和即时指令。
原件保持可检索；分流为参考资料不代表删除、永久无价值或不能由另一任务挖掘内容。

模型看到角色、标题、来源日期，以及带编号的连续原文片段。每条候选选择一个
`evidence_id`；服务按编号恢复原消息ID、原文引用和字符偏移，不接受冲突引用。
英文、中文、空格和Unicode不规范化，证据最多1000字符，长段优先在句末或换行处切分；未知编号拒收。
没有可抽取片段时返回空候选并跳过模型调用。

这解决引用抄写错误，不能证明陈述由引用支持。单片段可能不足以表达完整关系、
理由或否定上下文，必须回查完整消息。角色规范/指令分流是保守启发式，可能漏掉
值得作为项目做事规则保存的内容，因此保留原件和路由结果，不作语义批准。

版本化方法保持旧记录、旧输入和预算独立；真实难例结果另见当日评测报告。
