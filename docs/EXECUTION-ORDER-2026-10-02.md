并行边界：阶段1开发和阶段2材料冻结可并行；不在方法还在修改时消耗模型重跑测试集。阶段3/4在状态规则确定后可拆数据模型与只读接口，不能同时改同一迁移。阶段5/6不抢先绕过治理门槛。

阶段1放行条件：结构检查通过不足以放行；错误归属、缺条件、许可变强制或把计划当完成等严重错误须为零（针对冻结验收集），警告逐项保留。独立 Agent 审阅不叫人工 gold，不能外推全库准确率。测试不足或回归失败则保持暂停。

阶段2输出不得只有检索命中率。实际答案需要来源条款评分；无证据必须弃答，候选不得冒充已核实事实。三路线如无足够证据得出的正确弃答应与错误答案区分，不能让未作答冒充回答正确。开发集不能用作测试集；规则变化后另建版本，旧成绩不覆盖。
