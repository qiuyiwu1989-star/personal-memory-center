# 小批治理隔离试运行

本轮复用 v10 已完成的 10 份难例材料及 16 条候选，使用临时 SQLite Store 回放。没有新模型请求、生产数据库写入、预算改动或全量恢复。真实人物和长期状态没有得到任何自动确认。

| 环节 | 观察结果 |
| --- | --- |
| 原文归档 | 10 份输入，消息 ID、角色、正文保持一致；全部使用 archive 策略 |
| 提出候选 | 16 条保存过的模型候选再次通过现有证据校验；4 份输入保持空结果 |
| 候选预览 | 首次预览尚无旧候选，不改记录；匹配引用不等于语义核实 |
| 隔离选择采用 | 本地回放就绪凭据，选择 16 条加入 candidate；0 条进入核实状态 |
| 再次预览及关联 | 检出 16 条重复候选、44 个关联链接；同证据可对应多个陈述，不当作独立佐证 |
| 重复采用 | 第二次采用新增 0 条；相同已采用任务拒绝再次执行，不改旧引用 |
| 主题 Markdown | 生成 1 份文档、16 项陈述；保持待核实、二手摘要等区分 |
| MCP 读取 | 候选检索显示 16 条，可信 context 显示 0 条；文档分页完整复原，整包字符预算通过 |
| 权限 | 跨范围读取拒绝、只读代理不能导入或采用；原文读取需额外 source_read 权限 |

## 治理边界测试

新增 4 个纯合成测试，覆盖不升格和不调模型、明确纠正后其他代理读取新判断且旧引用可查、已过期及尚未成立状态不能进入 context、代理不能自行核实及其他用户不能预览私有来源。测试通过。

纠正和核实测试只针对明确标注为 synthetic 的例子。真实的 16 条候选没有登记身份、确认归属、设置当前有效状态或写入正式记忆。

## 试运行状态

技术闭环通过：`operational_pilot_passed=true`。这表示现有候选可经过预览、关联、选择采用、主题投影和 MCP 读取，并保持候选权限和历史边界。

质量决策仍未批准：`quality_approved=false`、`bulk_resumed=false`。可信返回 0 条证明没有隐式升格，不是检索相关性或有效事实召回成功。

这次 ready 状态是隔离回放的测试夹具，绑定既有验证结果；没有调用真实 worker 或声称新提炼成功。原材料属于局部难例采样，不是完整 Claude 导出文件；试运行不证明全库质量或生产 Postgres 下完整处理性能。

## 可复现入口

`scripts/pilot_memory_governance.py --input <private-paired-input> --results <private-v10-receipts> --output <private-new-report>`

输出路径必须位于公开仓库外，并以独占创建方式保存为 0600。报告保留输入及结果 SHA256、每份预览及关联、新候选标识、主题正文和 MCP 聚合指标；标准输出只打印计数与状态。临时数据库运行结束即清理，报告中的隔离标识不指向生产。

下一步结合独立检索相关性标注决定试点准入，再选择新的小批来源做真实提炼及人工语义抽查。是否批准质量和恢复派发仍是独立决策。
