## 如何使用与剩余边界

在网站后台进入记忆中心的“提交资料”，在资料卡片点击“治理账本”；也可从记忆管理中的同名入口追查来源。撤回先看影响，再明确确认。分段资料目前按每个来源版本分别处理，不能自动按父来源批量撤回。

没有代办账号登录，也不把服务端技术验收当作用户已登录浏览器实际操作。LocalVault / ArkClaw 自身运行环境的参数映射与完整个人记忆更正回路，仍需客户端侧真实联调。没有把合成治理测试当作真实记忆质量通过。

下一步：实际后台使用反馈 → 外围客户端小规模归档和读取联调 → 真实个人记忆质量评测 → 渐进式 Skill 与更多资料接入。全量 Claude 提炼和预算放行单独按质量门槛安排。
