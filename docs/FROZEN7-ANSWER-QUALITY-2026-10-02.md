# 冻结7份来源：三路线回答复核

主 Agent 以固定代码与回答提示完成21道题 × 3条路线的63次回答，独立 Agent 对照预先冻结的 rubric、可见原文和实际输出逐条审阅。完整评分及输入/输出 SHA256 收据仅存仓库外0600文件；本文不含个人原文。评分是 Agent 判断，非人工 gold。

## 边界

会话已预选且明确提供，比较的是已知会话下的回答、归属与安全边界，**不是全库检索、召回率或节省 tokens 的证明**。三路线为原文、原文加未确认候选、空可信记忆基线。候选并未采用，可信路线没有真实记忆输入。

## 正文与元数据分开看

两条有原文路线各有一次把第三方引文内的担忧与代问请求归成用户自述；原文路线还误读了引文的一项事实。该来源没有提炼候选，因此原文加候选路线的错误不能归因于候选污染。另有明确协作定义请求被概括为无需求、少量消息计数和粒度警告。

在助手建议是否采纳、历史资料能否说明当前运行或完成等问题上，多数回答正确保留了未知与未确认，没有观察到候选导致新的明确采纳/完成断言。但这不证明候选正确或提升回答，之前提炼审阅的失败继续有效。

部分答案正文说“没有证明”“未确认”“不能说明已完成”，却填 `abstained=false`。正文是安全负结论，不能按字段不一致直接判为幻觉。反向也有已知第三方归属题被写成不能确认、填 `abstained=true`，属于过度不确定。回答契约仍需明确区分拒绝无证据正断言、给出有证据负结论与缺少材料而无法回答。

空可信路线21次都安全拒答；其中15道需要具体历史内容或已知归属的任务没有得到实质覆盖。它是安全但无知识的基线，不能用零幻觉说明整个记忆中枢已经有用。
