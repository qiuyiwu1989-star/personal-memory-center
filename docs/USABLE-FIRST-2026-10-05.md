# 先用起来：本轮交付 · 2026-10-05

日常工作台入口已上线。可以先归档资料、手动补充个人记忆、核实和纠正候选；这些操作不调用模型，也不受现有提炼预算暂停影响。生产保留稳定 v17，本轮未恢复 Claude 整批提炼。

## 现在怎么用

1. 在本人网站后台进入记忆中心。点击「拖入资料 · 先归档」保存原文；新资料默认进入 personal 资料范围，但归档不会自动成为可信个人记忆。
2. 点击「补充个人记忆」填写陈述；入口明确切至 personal，不误写进 Claude 历史。保存为候选。
3. 点击「核实当前范围候选」核对原话、谁的观点、关于谁及实际成立时间。本人实体始终可选；未知信息继续留空和保留候选，不能用保存日期冒充成立时间。
4. 明确核实后，Agent 的 memory_context 才能按需取得这条当前可用记忆。更正形成新版本，旧版可追溯；撤回后不再作为当前事实。
5. 「Agent 接入」中为每个 Agent 分别管理读取凭据和隔离收件箱写入凭据；具体连接和自测见 [中文快速接入说明](AGENT-QUICKSTART-2026-10-05.md)。不要把网站密码或火山 LLM Key 当成 MCP Token。

配置管理、版本对比、Skill 附件导出和有限关系视图沿用上一轮已上线功能。模型接入点与输出参数按范围管理；密钥仍在服务器私有配置，后台任意新服务商和换密钥入口尚未实现。

## 本轮完成与验证

- 日常 UI：三个轻量入口、空个人范围引导、预算暂停提示、切换范围刷新修复、核实后筛选变化说明。仅 HTML/JS 上线，后端、CSS、PID不变，无重启。
- 合成浏览器实测：零预算归档以及新增候选 → 本人实体/成立日期明确核实 → 可用记忆。未冒充本人真实登录操作。
- 接入包：单 Token MCP 初始化、工具发现和默认 1,600 字符可信上下文读取；候选需显式请求，不做空 personal 的自动回退。Token 只从环境读取，不输出正文或凭据。
- 长文请求：完整原件重核验、有界 DATA、原消息 ID 与证据定位、角色/参考路由、跨边界拒绝裁剪和部分语境标记。development 6来源得到8请求，2742证据字符，其中3请求部分语境；不等于语义质量通过。
- 显式开发模型入口：`Model(store, method_version='2026-10-04.22').extract_bounded_source(...)` 重新构建请求，检查本人权限与已有账本预算，稳定试跑键拒绝重复调用，按模型实际/未知用量结算。不会提高额度、创建记忆或确认质量，未接生产 worker。
- 集成 **546 项 Python / 20 项 Node 全通过**；公开扫描及差异检查通过。本轮全部模型调用为0。

生产前后数据、治理、任务、批次和预算聚合一致。Claude仍paused_budget；未改grants、key或personal内容。真实运行侧 ArkClaw/LocalVault 与本人生产浏览器操作仍需在实际使用中验收。

## 接下来边用边迭代

日常归档、手写与审核可以先使用。新增提炼需要有限预算；目前历史范围通用预算耗尽，不暗中提高额度。先在完整原件绑定的请求上进行真实小批质量试跑与独立评分，再决定生产 worker 适配和 Claude 分批恢复。其他文档和会议可先归档，不必等全量 Claude 完成。
