这是第一批实现与基线，不表示整项计划已经完成或上线。

## 生产基线（只读）

Claude 历史范围共 2,189 条抽取结果：502 条 source_reported、980 条 agent_suggested、707 条 imported_summary。批次 900 个分段，累计 1,967,655 / 2,000,000 tokens，状态 paused_budget。没有恢复批次、修改结果或调用模型。

已私有保存 50 条确定性分层样本：17 条原话提炼、17 条助手材料、16 条旧摘要。50 条引用都存在于相应来源；初步对照发现至少一条用仅表示“继续”的消息支持具体章节、年龄阶段和家长角色等扩展结论。引用存在不能代替语义支持。此发现只说明该样本的风险，不是全库错误率。助手内容与旧摘要保留对应来源分类；目前没有把样本批准为当前事实。

样本含个人材料，未放入公开仓库。逐条完整上下文核查、用户真实任务的召回评测和文档质量评测仍待完成。

## 已实现

- 增量 companion tables，不修改旧 records 的列数和历史：归属、稳定对象引用、成立/失效日期、治理状态、优先级和审核事件。
- legacy active 默认 candidate；本人纠正单独标识。本人核实需明确主张者、对象、成立日期；不从入库时间补造成立时间。
- 核实 API 校验所有权、范围、本人权限和审核版本；保留每次审核前后状态。
- memory_context 默认只读取已核实/本人纠正且未失效的记录；整个返回对象受字符预算约束。不是精确 token 计费器。
- 主题 MCP 正文分页，可无损读取；候选搜索保留治理标签。
- MCP 小批导入默认仅归档，不调用模型；来源元信息保留原件引用、作者、定位和解析版本，不能改变服务端权限。
- 重提炼输出的证据校验与差异预览：新增、重复、相关旧记录。预览不修改旧记录、不伪称语义已核实、不调用模型。
- 原有管理卡片显示候选/核实/历史状态与成立日期；归档资料明确显示未调用模型。
