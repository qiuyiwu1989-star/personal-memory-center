# 记忆中心上下游扩展交付与后续安排

**发布更新：** 2026-10-07 已完成独立 PostgreSQL 演练、迁移010及稳定版增量上线，公网验收通过。以下保留本轮开发交付时的边界；实际部署状态以[上线记录](INTERFACE-PRODUCTION-2026-10-07.md)为准。

本轮完成三条并行开发线及中心集成：上游候选收件、下游变化检查、后台逐条治理。交付为本地可用版本；没有把开发分支直接覆盖线上稳定提炼方法。

## 本轮完成

| 工作 | 可用结果 | 验收边界 |
|---|---|---|
| 上游候选 | `memory_candidate_submit` / `POST /candidate-intake` 接收原文定位与候选，返回幂等回执 | 1–20 条；同来源创建者；独立 candidate_write；不确认事实、不调用中心 LLM |
| 后台收件 | 提交资料中显示候选批次、状态、来源账本；逐条核实、补充、修改 | 单条详情重新检查身份/范围；撤回及取代记录仅供审计 |
| 下游变化 | `memory_changes` / `GET /changes` 检查记录版本、治理状态、有效时间、撤回及取代 | 当前元数据检查点，非完整事件增量；变化后按任务重读可信上下文 |
| 接口发现 | `memory_capabilities` / `GET /capabilities` 告知范围权限、迁移是否就绪与实际默认策略 | 工具存在不等于有权使用，也不表示客户端安装成功 |
| 权限及证据 | 修复普通 Agent 通过历史列表取回撤回引文的旧入口；上游来源定位可回看 | 历史审计要求本人身份及 source_read；不修改旧读凭据 |
| Skill | 上游归档后可显式提交候选；下游渐进读取及变化后刷新 | 仓库版本已更新，未替其他设备安装；参考文档随完整 Skill 目录交付 |

本轮私有工作台载入此前准备的 **4 份原始消息、8 条候选**，全部逐字校验证据并保留来源。仅使用开发材料，未消耗保留的独立验收材料。写作要求中的四条来自同一段发言，不能作为四次独立支持。人物身份、成立时间、当前有效性仍未知，因此可信记忆为 0。没有调用模型、修改生产数据或提高预算。

## 协作约定

1. 外围节点选择已获授权的材料，保留原始角色、正文、日期、定位与版本；先归档并持久化来源回执。
2. 外围可以提供已经形成的候选，也可以只交原文。前者走候选接口，中心不重复调用模型；后者需要提炼时按独立质量及预算流程排队。
3. 中心核对证据位置、来源创建者、权限及幂等键。合法候选进入收件范围，初始身份和有效时间不推断，不能直接变成 personal。
4. 本人通过工作台核实归属和时间、补充、修改或不采纳。更正保留历史；匹配原文不等于语义正确。
5. 下游先按需读少量可信上下文；查证时再找候选及原文。持有旧上下文时检查版本，变化后重新检索，不整库注入提示词。

REST 路径均相对 `/api/inside/memory-center/v1`。可信上下文是 **GET `/task-context`**；旧 POST `/context` 仍返回候选。归档客户端始终显式传 `processing_policy=archive`；MCP 默认 archive，但旧 REST 非 archive-only 凭据可能默认 extract。

检查点对整个范围扫描元数据，服务端成本为 O(N)，输出字符数有界，中心模型调用为 0。它不覆盖仅归档而未形成记录的来源、COS、配置或文档变化，也不是跨 Agent 强制清缓存机制。按实际任务复用时检查，不自动创建周期轮询。

## 已验证及尚未验证

- Python 全套 **620 项通过**；Node **37 项通过**（含单文件中的 8 个文件校验断言）；公开树扫描通过。新增测试包括引用偏移、并发幂等、整批回滚、撤销授权、跨范围、MCP/REST 完整治理和缓存失效。
- 真实资料只写入仓库外的独立 SQLite；界面实测了候选展开、原文证据和核实表单，没有替用户提交任何确认。
- PostgreSQL 迁移 010 使用 DOUBLE PRECISION 保留时间精度。演练脚本为 `scripts/check_candidate_intake_migration_pg.py`，只接受显式本机、空的 `memory_intake_scratch_*` 数据库，DSN 从私有环境读取，不打印。
- 当前机器没有可用 PostgreSQL，真实 PG 演练未执行。迁移脚本防误用测试和数据库适配器只读事务测试不能替代真实演练。读取不会自动建表；迁移缺失显式显示不支持。
- ArkClaw / LocalVault 实际运行实例、生产迁移和发布尚未做。既有 LocalVault 兼容补丁验证的是归档通道，不能据此宣称上游已实现新候选协议。
