# N03 新独立来源评测准备

本轮只准备冻结材料与私有评分协议。未运行模型、未配置预算、未写生产记录。
150,000 tokens 是第一轮复测预算提案，不是本次支出或已生效额度。

## 选样与独立性边界

从授权 Claude conversations.json 原件选完整可见会话，排除过去提炼/评测输入、
50 条来源审阅涉及的会话和消息、已执行历史批次以及旧 7 份来源。旧 7 份不再称未见。
排除收据逐文件记录 hash；旧批 planned/pending 只表示排队，不能误当已经执行/已读。

选择规则先固定：2–100 条完整可见消息，最多80,000可见字符，原角色与原日期齐全，
无附件/工具依赖；结构化 thinking 不作为可见内容。采用固定 seed 的 UUID 哈希排序，
不根据问题、预期答案或主题挑选。取消旧集“本人发言至少30字”的限制，保留短问题场景。

365 个会话中：63 个命中已见来源/已执行收据，15 个不满足消息数，279 个有附件、工具或
未知依赖；最终8份完整会话、29条消息、15,192可见字符。来源选择先冻结，之后独立设计题目。

“独立”仅指未出现在列举的本机开发、来源审阅和已执行收据中，不保证没有历史人类阅读、
未记录的其他服务处理或模型训练接触。原件 hash、逐会话 canonical hash、可见消息 hash、
角色、日期、定位和选择排序均留在私有收据。正文、题目、答案、ID 不进入公开仓库。

## 交付与执行分离

私有 n03-new-input-v1.json 只有 cases 和来源收据，无题目或答案；兼容当前评测运行器的
sample_index / source_type / messages 结构。独立评分文件另存0600，执行者不读取 rubric。
提炼方法与回答契约冻结后再构造模型请求，运行器只取得必要问题，不取得期望语义与答案。

- 8份来源已冻结；16题独立评分协议采用 source-answer-v2，冻结在模型运行之前。
- 覆盖归属、问题与观点区分、未证明采纳、条件、历史与当前状态、复合/跨消息引用、
  重复来源与不确定性等风险。
- “材料不能证明采纳”可以是 answered 的边界说明；“当前最终状态是什么”而只有历史讨论，
  为 insufficient_evidence。前者不等于明确未采纳，后者不得以旧说法代答当前事实。
- 字段校验、引用命中与语义判定分别报告，不把模型自评或独立 Agent 评分称人工 gold。

## 不能据此放行的能力

这些来源多数是简短用户提问与较长助手建议，缺少外部角色/多人会议、明确采纳的最终决定、
已确认的事实撤回/失效事件。因此这个小集可检验归属和过度升格，不能独立估计真实决策的
召回率、全库检索率、外部引文内说话者解析或完整更正传播质量。通过也只对这份验收集成立。

正向决定、外部发言与有效期更正应另用明确授权的新会议/文档准备独立来源；合成回归可先
验证守卫，但不能冒充真实来源质量。这些覆盖缺口不通过硬凑旧来源或临时改题消除。
