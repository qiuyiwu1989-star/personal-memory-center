# 来源回答契约 v2

`pipeline/memory_center/answer_contract.py`保存冻结的评测回答提示与结构验证，版本为source-answer-v2。它不调用模型，不改变产品读取的默认成本，不提高任何候选或正式记忆的可信状态。

旧7份开发评审发现：合法引用下仍可能将转贴来信内部第一人称归给用户；安全的“资料不能证明已采纳”答案可能填abstained=false，而评分把字段差异误当正文错误。新契约明确区分消息提交者与引文作者，保留历史和未采纳边界；复合回答须覆盖每个实质子句。

新增evidence_status：answered为基于来源回答实际问题，包括指出资料能支持的边界；insufficient_evidence为材料不足以回答所问事实。abstained严格对应后者。例如问“是否有采纳证据”，指出仅有助手建议可以是有依据回答；问“现在是否采纳”，只有旧建议不能说明当前状态，应保持未知。两者都不得断言明确未采纳。

输出验证检查字段、布尔类型、状态对应、引用ID及列表。answered须有可定位出处。引用合法不保证归属或蕴含正确，合成测试显式演示机械校验仍会接受语义误归属；真实质量仍由独立来源审阅验收。

后续真实试验必须使用该固定提示而非旧私有脚本硬编码，绑定提示hash、方法版本、完整输入及实际模型输出。冻结题目与rubric不发送给回答模型；开发旧7份不再称未见测试集。新题expected_abstention标注按本契约定义，无法判断时标人工/独立审阅，不事后为了分数改题。

本轮仅完成契约和合成验证；尚不能据此称真实归属问题已解决。
