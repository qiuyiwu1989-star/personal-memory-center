# 本人维护与资料可见性：轻量UI接入

仅调整现有工作台HTML/JS，不创建接口、不扩大权限、不执行迁移或部署。

- 新增、修订和审核都可选“此次变化类型”；默认未指定，不发送新增审计字段，保留未应用
  007服务器的旧流程。指定类型时服务端如未迁移，原错误直接显示，不假装成功。
- 仅旧记录修订/审核可选本人观点改变或撤回；旧事实失效日期仅在观点改变时显示和发送，
  未知留空，切换类型清空，不自动填今天，不当作系统记录时间。
- 撤回是审计类型，不单独等于退出可信上下文。修订需本人明确勾选设为不采纳；审核需本人
  选择不采纳，否则阻止提交。不会静默沿用verified或自动核实，也不删除旧来源/版本。
- 资料可见性默认未知，不发送visibility字段以兼容旧服务器；明确选择时经既有source_metadata
  提交visible_only/complete_visible。完整可见只是本次文字声明，不表示附件、工具或链接核实。
- overview如有projection状态才显示简短刷新提示。只有ready + stale=false + since-migration-only
  才显示“接入审计后的本人修改已刷新”；未知/不可用不当ready。不代表所有Agent旧缓存已更新。

新增7项前端契约测试，以合成DOM/传输执行真实表单回调：默认兼容、观点改变日期、显式撤回、
审核撤回不能保持verified、保守projection显示、治理payload与visibility。加原3项文件测试共10项
通过；Node语法检查通过。此测试不代替真实浏览器视觉验收、真实服务器权限或007恢复演练。
