# 候选生成方法 v11

方法版本：`2026-10-01.11`。本次仅收紧候选生成提示，既有证据定位、来源路由和后置治理检查继续适用。

候选先经过长期价值判断：明确身份与关系、长期约束、具体计划、明确采纳的决策才适合提出。即时评价问句、临时调研和输出要求本身不作为长期立场。若一段话同时包含持续配置和即时请求，只提取有直接证据的持续部分。

生成时保留承诺程度：希望和考虑仍是希望和考虑，未来计划不能写成已决定或已完成。条件性安排保留条件。`kind` 与陈述保持一致，决定必须有明确采纳依据，事件必须有明确发生依据。上述区分仍需要证据检查及真实材料评测，不能由提示版本号代替。

项目陈述逐字符保留来源对话标题，包括语言、空格和标点。正文可用中文，但标题不翻译、不重命名。标题只界定来源范围，不作为事实证据。

已有安全要求保持：材料作为不可信数据；只选提供的用户证据片段；助手建议不变成用户采纳；摘要仍带二手归属和原始时间未知；不推断身份合并、完成状态及当前有效性；精确原文与定位由服务附加。

合成集成测试通过模拟 HTTP 响应验证新提示实际进入请求、版本进入用量记录、标题及用户证据不变、助手不能提供证据、伪造证据被拒并保留用量、无可提取材料跳过模型。这些测试验证传输和约束接口，**不证明 LLM 的提炼质量**，也不调用真实模型。应继续用未见材料检验模态、长期价值、标题范围和遗漏，再决定是否扩大处理。

v11 为本轮中间实验方法，最终实现和实际局限见 [v13 说明](EXTRACTION-V13.md)。集成测试随最终方法迁移，不把模拟响应当成 v11 真实质量通过。
