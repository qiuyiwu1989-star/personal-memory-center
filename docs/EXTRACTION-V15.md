# N01 提炼契约 v15

方法版本 `2026-10-02.15`；独立诊断版本 `extraction-quality-review-v2`。本轮只修改代码及合成回归，不消费模型额度、不修改生产候选、不恢复旧队列。旧 7 份来源及问题已成为开发集，不能再次作为未见验收。

改动针对三个开发集暴露的问题：外层用户提交的第三方引文中，第一人称及其担忧、请求仍归引文说话者；每个复合主张的所有成分必须由所选单一证据支持；临时问题旁独立的资源、角色或关系自述应考虑保留为历史候选。用户提供的草案或共同定义请求不等于已采纳决定。已有来源日期、准确标题、精确 offset、条件及模态守卫保留，v13/v14 历史 resolver 继续兼容。

诊断只提供警示，不替代语义审查：

- `nested_speaker_review`：来源含第三方来信/自述信号而候选提及用户，要求逐个子句核对归属。真实用户转发自己的信也可能触发；不自动拒绝或改主体。
- `enumerated_coverage_review`：列举多个成分时逐项检查单 span 覆盖。逐字引用存在、分号或顿号数量均不证明支持或错误。
- `source_signals[].historical_self_report_review`：未产生候选的用户消息同时有资源/角色自述与问题信号，提醒回看可能遗漏的历史事实。仅提供消息序号与固定解释，不复制原文；检测到引文信号时不作此提示。它不检测所有持久事实，也不能证明遗漏。

所有输出仍标记 `quality_approved=false`、`semantics_verified=false`。`review_required` 和 `archive_only` 仅为后续治理建议，候选、原件及正式状态不被改写。未产生警示也不意味着合格；`source_signals` 至多 32 项，逐候选 findings 至多 6 项。

合成验收覆盖：模拟 provider 的第三方引文误归属产生待复核提示；自述旁问题零候选产生元数据提示；多成分概括产生覆盖提示且不伪造引文/删候选；独立自述不被临时任务全局误杀；v13/v14/v15 标题日期与 offset/模态兼容。模拟响应只验证适配器及诊断行为，不能证明新提示能使真实模型正确提炼。

剩余风险：引文起止与说话者不明、跨语言同义概括、跨 span 必要上下文、草案长期价值以及事实当前有效性需要独立真实复测与治理裁决。新独立材料的严重错误门槛、遗漏和警告必须分别报告；旧集修复或工程测试绿色不能放行批量提炼、可信采用或自动确认。
