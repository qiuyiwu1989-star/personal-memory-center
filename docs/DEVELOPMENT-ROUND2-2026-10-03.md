# 记忆中心并行开发第二轮

2026-10-03，继续用户批准的执行安排。三路 Agent 分别完成质量固定集、候选读取优化、接入自检，主 Agent 合并并补充后台状态展示。

## 已完成

- **质量固定集**：17 个明确合成探针，覆盖本人决定、第三方建议、条件性承诺、后续更正及需要→计划。确定性契约检查 17/17；这不是模型语义准确率。质量提示升级 review-v3，新增第三方归属和承诺强度待审提示，不自动拒绝、确认或升格。
- **候选读取**：默认 lexical-v1 精确扫描匹配总数，只保留排名窗口并读取最多 128 条记录对应的来源。相同时间记录按 ID 确定排序；窗口覆盖与遗漏显式显示。实验 v2/v3 保留全读取兼容路径。
- **接入自检**：可执行的进程内 MCP 自检覆盖无损分段、角色、重试幂等、版本留存、原文预算、归档与索引状态、权限和撤销。输入检查只输出汇总与摘要 hash；不打印资料正文。
- **后台展示**：卡片展示谁认为、关于什么、成立及失效时间；区分当前可信、已核实但不可用、旧纠正待复核。编辑后保存候选，审核后才可进入可信上下文。

## 验证

355 项 Python、11 项 Node 测试通过；公开树扫描通过。模型调用 0；未改变预算、恢复全量提炼、发行凭据或升格任何个人记忆。

10 万条本地 SQLite 合成测试（无原文索引、两次未加 tracing 的耗时观察）中，证据包中位耗时约 **0.534 秒**、Python 分配峰值约 **7.19 MB**；上一轮同参数分别约 2.696 秒、217.36 MB。匹配候选总数仍为 99,000。回执保留在私人目录，不包含真实来源。该测试不代表生产耗时、p95、原文召回或语义质量。

## 仍需完成

1. **P0：真实语义验收**。旧 case5 未复测、未判通过，quality_approved 仍 false。保留更正后的旧计划可能逃过词法提示这一反例；固定合成集不能替代独立模型试验与语义复核。
2. **P1：Agent 可用的窗口续读**。目前 coverage 是诊断字段，续读只在内部 Python 方法支持；公开 MCP 还未支持 offset。需要定义可用的续读接口、遗漏检查及大资料读取方案。
3. **P1：进一步成本控制**。默认候选仍需 O(N) 轻量扫描；PostgreSQL 普通 cursor 可能缓冲这些行。最多 128 条来源不代表字节有界；原文索引和实验模式也仍可能全量读取。
4. **P1：可信 personal 内容**。不能自动将 159 条原子或 Claude 候选认定为本人当前判断，仍须确切内容与出处确认。
5. **P2：实例联调**。本机未发现 LocalVault checkout，未声称核实其源码。真实 LocalVault/ArkClaw 客户端、重启补偿和删除传播待实例侧验证；没有新增 inbox、权限或生产同步任务。
