# 第二轮：条件范围诊断与评价前约束

本轮完成的是**保守、可审计的离线范围诊断**，不是条件语义修复，也不是新版提炼上线。没有调用模型、连接生产、写入记忆或改变提炼版本。

## 为什么仍然保留已知失败

冻结的合成验收要求：

> 我希望项目 Atlas 保留每条原始证据。如果独立评测通过，我计划发布项目 Orion。

期望是把独立愿望与另一个项目的条件计划正确区分。当前 v19/v21 仍保守保留一个证据片段；第一个愿望可能受到整个片段的条件守卫影响。不同项目名称只是表面信号，不能可靠排除共同条件、代词回指、后置限定或第三方引述。因此本轮没有通过识别两个名称就放宽提炼守卫，也没有改动该测试的目标或 `expectedFailure` 标记。

## 本轮新增

`pipeline/memory_center/scope_diagnostics.py` 提供无需 LLM 的原文导航：

- 条件关键词的原始 Unicode 偏移与逐字引用；英文 If/unless 同样保留。
- 按表面标点产生无损显示单元，方便比较条件之前与之后的内容。
- 显式命名项目、可能回指、引述及列表的表面观察，全部保持范围关系未成立。
- 明确标记显示单元**不是 evidence span**，不能将不含条件关键词的显示单元当成无条件承诺。

`scope_review.py` 的私有完整来源包增加这些观察，并计算实际证据字符覆盖。没有可抽取证据的消息也进入复核目标，不再因为缺少条件词而从诊断中消失。每个服务端片段都逐字绑定源文，源文和邻接消息继续完整保留。

这些结果不含采纳接口，不生成新 `claims`，不影响原运行时切段。生产 v17、实验 v21 保持原来的边界与方法语义。通过机械诊断不代表语义正确、本人观点、授权成立或当前有效。

## 两种诊断各解决什么

| 模块 | 用途 | 不能证明什么 |
|---|---|---|
| `input_coverage.audit_input_coverage` | 在输入评价前核算来源/证据字符、超过 20,000 字符的消息和需要分段的输入 | 不能证明证据保留了语义与条件，也不保证 provider token 能容纳 |
| `scope_review.prepare_scope_review` | 对符合当前正文上限的消息生成带完整邻接上下文的私有范围复核包 | 不自动划定条件范围，不放宽现有守卫，不确认候选 |

两者仅为离线诊断；字符覆盖率不是提炼质量指标。完整证据覆盖仍可能产生错误归属或遗漏条件。

## 必须先解决的输入限制

1. 当前提炼输入会把长文本逐段限制为约 1,000 字符片段。即使全部原文字数都存在于不同片段，后面的候选仍可能丢失前文条件。包内 `selected_piece_not_complete_condition_context` 对此报警；本轮没有修复运行时切片。
2. 长会议或文档可超过每消息 20,000 字符，不能直接送入当前治理接口。须先做有原始偏移、覆盖收据和上下文依赖的输入适配，再评价。不能静默截断。
3. `reference_document`、`mixed_reference_document` 路由可能排除有价值的正文。这种排除是当前输入策略，不是低价值或质量通过的结论。空输出、少量证据和少量候选不能直接视为成功。
4. 角色和来源映射要准确：本人消息、导出用户消息、作者未知文档不能混为一类。文档中的第三方观点也不能因为 `external` 文本含“我”就当成本人观点。

## 验证

44 项相关测试：43 通过、1 项既有期望失败保留。新诊断 8 项测试全部通过，覆盖普通不同项目例子、后置条件、引用/列表/回指、英文及 emoji 偏移、长条件上下文、零证据输入和 v17 边界不变。

测试命令：

```sh
.venv/bin/python -m unittest tests.test_memory_scope_diagnostics tests.test_memory_scope_review tests.test_memory_scope_v19_adversarial tests.test_memory_scope_v19 tests.test_memory_condition_scope tests.test_memory_qualifications_v21
```

## 后续验收顺序

先完成长会议/文档输入适配，再从真实完整上下文标注愿望、条件、主语、后续更正与成立范围。开发样本用于定位错误；独立未曝光保留样本用于验收，曝光状态未知时不能声称盲测。

需要用相反案例验证范围规则：相同项目不同条件、不同项目共同条件、后置条件、否定、回指、第三方引述及会议多人发言。没有满足这一轮语义验收前，不应仅靠正则切出普通例子的两条记忆，也不应恢复全量提炼。
