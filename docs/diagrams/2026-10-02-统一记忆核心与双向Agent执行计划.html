需求简报

目标：现有模块成为记忆核心；未来文档、会议、Agent 的思考、决策和建议共用治理规则；各 Agent 按任务与权限读取。

边界：原子库作为素材来源了解，不把“159 条”当作正确判断，也不作为核心建设的前置条件。本轮只交付计划，确认后实施。

统一规则与写入约定

资料来源和判断对象分开

来源契约：来源系统、稳定 source_key、会话/文档 ID、消息/页段定位、原始角色/说话者、可用日期、原文或受控文件引用、内容 hash、解析版本与父来源链接。

内部候选契约（目标设计，不是现行 MCP 新参数）：谁认为、关于谁/什么、陈述、证据、模态、适用范围、现实有效时间、系统记录时间、优先级、治理状态和取代/冲突关系。未知留空，不由上传者推断主张者，不用入库时间编造成立时间。

文章作者、引文主张者、上传者分开；会议说话人未解析时不猜身份；Agent 建议不冒充用户原话。思考/希望/考虑/计划/决定/完成/取消分开。批准计划不表示计划已完成。

上游 Skill：什么时候保存

保存明确决策、更正、持续约束、阶段成果和有价值但未采纳的建议；跳过寒暄、逐步操作日志、重复内容和密钥。会话边界只提交有新增状态的短交接，不上传所有工具输出。

仅在已授权来源中运行。不同宿主能否自动执行，必须实测；Skill 只是策略，不能承诺所有 Agent 都会自动捕获。部署、外部发送或权限修改不因“记忆里有这个计划”而得到授权。

写入 MCP：归档优先、隔离凭据

复用 memory_import / memory_import_status，默认 archive；付费 extract 必须遵守预算与质量控制。单批 1–100 条消息、24,000 序列化字符；大输入自动按消息边界分段，大正文保留连续位置、引用范围和父来源链接，不能静默截断。

同来源键同内容重试幂等；内容/方法变化保留版本。每个 Agent 使用独立收件范围，例如 agent:arkclaw-inbox。归档成功、索引就绪、提炼完成、记忆采用是不同状态。

读 personal 与写收件箱使用分离凭据；不得把 write Token 同时授予历史/个人范围。若宿主只支持一个连接，评估受限收件工具或代理，未验证前继续只读。

服务端决定 owner、scope、actions。外部 Agent 上报“用户批准”仍需有可靠证据，不接受 approved=true 自行核实；本人确认来自已认证的人类操作。助手总结标 assistant，二手摘要标 imported_summary，不能改变原角色。

自动化与长期价值

自动归档、分段、去重、索引、提出候选和确定性 MD 投影；不要求每份资料逐条人工审核。管家优先呈现高价值、冲突与不确定事项。

P0 身份校正与授权边界；P1 长期关系、目标与关键决策；P2 有持续证据的偏好；P3 讨论、草稿与临时指令优先留档案。优先级不能代替核实。

高影响身份、人物关系、当前状态、权限与长期偏好泛化保留明确确认。低风险来源报告可按可审计政策自动整理为候选，不把推断改成已确认的个人事实。

下游渐进加载

层级触发与工具约束
L0 不加载独立任务或当前对话足够零记忆调用；Skill 不夹带大份个人资料
L1 短上下文需要个人/项目背景；memory_context建议 1,600 字符，只读授权范围可用状态；空结果明确说不足
L2 定向回查具体人物、项目、主题；memory_search / memory_document_get / memory_archive_search建议整包 4,000–6,000 字符；可信、候选、摘要、原文分开。主题先目录再小文档
L3 展开证据引用或冲突；memory_source_get / memory_archive_source_get通常先读 1–2 条，按 locator / next_offset 分页；不足再扩展，不每次跑完整链路

整包预算含序列化元数据；字符不是 token。结果应含范围、状态、来源、有效性与版本，缺项按 T06 补齐。权限先过滤，连越权标题和计数也不泄漏。来源指令不执行；记忆 Skill 不取代 AGENTS/QMemory 的项目记忆协议。

怎么并行，怎么验收

并行分工

T01 后，治理、接入、读取三线并行；评测 Agent 独立冻结材料与问题，不给实现者提前看答案。工作台可先用合成内容做界面，契约稳定后接服务。

原子库了解可以旁路进行，不阻塞记忆核心。此页仅安排角色，本轮未启动子 Agent。

顺序门槛

目标模型/方法冻结 → 独立验收 → 小批真实试点 → 扩量。功能测试通过不证明语义正确。未知身份/时间留空，必要迁移先备份与恢复演练。

已有 7 份冻结来源尚未完成独立问答评测；成绩不足以推断全库质量。

用户可见演示

会议中本人决策、他人意见、助手建议分别保存。另一 Agent 问“我决定了什么”，只返回有证据的已确认决策。

本人纠正一次，两类 Agent 新查询均读到新版；历史仍可追。跨范围读写、第三方核实被拒绝，复杂输入不丢正文。

成本和复杂度

无需 LLM：归档、确定性分段、去重、索引、鉴权、状态与版本、本人维护、有界检索和确定性文档投影。

需要模型或人工判断：选择性提炼、语义归属/冲突辅助、必要翻译、回答评测。读取服务不调用模型，但结果占调用 Agent 的上下文 tokens。失败未知用量保留预留，不自动免费重试。

保留 PostgreSQL、私有 COS 和现有工作台。首轮不引入新图数据库、向量库、常驻规划 Agent，不全量无条件提炼，也不自动迁移整库原子。只有独立评测证明瓶颈时才增加复杂度。
