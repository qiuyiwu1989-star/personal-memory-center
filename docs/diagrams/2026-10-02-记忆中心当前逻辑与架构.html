主题 MD 与任务证据

主题文档是数据库记录的派生版本；包含候选时仍需显示其性质。任务证据包将可信、候选、原文分组，整体控制返回长度。
目前的质量关卡：已有真实试验暴露的语义错误尚未全部消除，复核提示的合成测试通过不等于真实记忆通过。全量自动提炼继续暂停；归档和原文查询照常使用。

Agent 读取：由少到多，按任务展开

1 · 判断是否需要个人背景

Skill 指导调用策略

任务自带足够信息时不查记忆；需要背景时使用已授权 scope。Skill 不能替 Agent 获得额外权限。
2 · 少量可信上下文

memory_context

建议先 max_chars=1600。只返回治理后仍可用的上下文；没有结果时不偷偷放入未核实候选。
3 · 检索候选与历史材料

memory_search

按任务词检索陈述候选，保留来源和治理标签。找到相似陈述不证明观点属于你，也不证明现在有效。
4 · 查原文补证据

memory_archive_search

额外需要 source_read；建议上限6000字符。带角色、材料类型、时间和 locator；摘要显示二手来源。
5 · 必要时展开出处

memory_archive_source_get

locator 原样传回，offset 分页，建议 max_chars=4000。已知来源也可用 memory_source_get；过期引用和越权读取被拒绝。
6 · 形成任务回答

Agent 使用分层证据

区分原话、助手建议、旧摘要与已核实结论；引用出处。证据不足就说明未知，纠正走授权写入而不是直接覆盖。
以上每次读取 → owner / scope / action 校验 → 有界返回；记忆服务不调用 LLM
全部 9 个 MCP 工具与证据包的边界

memory_context · memory_search · memory_document_get · memory_source_get · memory_import · memory_reextract · memory_import_status · memory_archive_search · memory_archive_source_get

MCP 当前没有独立 evidence_bundle 工具。分组证据包是 REST 能力：可信上下文、候选、原文分组，整体长度预算；超限先移除原文条目，再候选，最后可信条目。当前不是跨组融合排序。主题 MD 通过 memory_document_get 分页读取。

读取成本

索引、词法检索、分页和治理筛选不消耗提炼模型 tokens；返回文本仍会占调用方 Agent 的上下文 tokens。

max_chars 是字符上限，不是精确 token 上限。默认渐进加载，避免大段全文常驻。

质量评测现状

已见16份材料、32道挑战题，三路线96个证据包长度达标。

答案生成/评分未完成，真正未见测试尚未冻结；上述结果不能证明回答正确率。
